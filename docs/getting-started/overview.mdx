Bitnob is financial infrastructure for bitcoin, stablecoins, and local currency rails across Africa. You build on it through one of two APIs:

| | Bitnob Business API | Bitnob Enterprise API |
|---|---|---|
| What it is | Bitnob holds the balance and settles payouts, cards, trades, and deposits for you. | Non-custodial wallets with policy-governed signing across chains. |
| Base URL | `https://api.bitnob.com` | `https://api.platform.bitnob.com` |
| Authentication | HMAC-signed requests | An `X-API-Key` header |

Not sure which you need? [Choose a product](/docs/choose-a-product) compares them in more detail.

## A typical Business API integration

Most Business API products follow the same shape, so learning one carries over to the rest.

<Steps>
  <Step title="Create a customer">
    Most balances and payment objects belong to a customer, not to your account directly.
  </Step>
  <Step title="Fund a balance">
    Receive bitcoin or stablecoins to an issued address, or take NGN through a virtual account.
  </Step>
  <Step title="Quote, then execute">
    Conversions and payouts are quoted first. A quote is only valid for a limited window.
  </Step>
  <Step title="Confirm with a webhook">
    Money movement settles asynchronously. Treat the webhook as the source of truth, not the API response.
  </Step>
</Steps>
