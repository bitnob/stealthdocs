Learn how to listen for stablecoin events that happen on your account.

A webhook is a URL on your server where we send payloads for transaction events. For example, if you implement webhooks, we will immediately notify your server with a `deposit.success` event once a stablecoin deposit is confirmed on-chain. Whenever you receive a webhook notification from us, return a `200 OK` to avoid resending the same event again from our server.

<Note>
  Signature verification, retries, source IPs, and local testing work the same way for every Bitnob Business API webhook. They're covered once, on [Webhooks](/api-reference/webhooks).
</Note>

### Webhook

Stablecoin webhooks are fired when a customer sends or receives stablecoin.

### Deposit stablecoin success

This webhook is fired when a stablecoin deposit is successfully confirmed on the blockchain.

<ResponseField name="event_id" type="string">
  A unique identifier for this webhook event. Use it to de-duplicate deliveries, since the same event may be sent more than once.
</ResponseField>

<ResponseField name="event" type="string">
  The webhook event type indicating a successful stablecoin deposit. In this case, it is always 'deposit.success'.
</ResponseField>

<ResponseField name="address" type="string">
  The receiving wallet address where the deposit was sent. This belongs to the user or your system.
</ResponseField>

<ResponseField name="amount" type="string">
  The deposit amount represented as a string in the smallest unit of the currency (e.g., '9000000' for 9 USDT).
</ResponseField>

<ResponseField name="chain" type="string">
  The blockchain network where the deposit occurred (e.g., 'tron', 'bsc', 'ethereum').
</ResponseField>

<ResponseField name="currency" type="string">
  The currency received in the deposit, such as 'USDT', 'USDC', etc.
</ResponseField>

<ResponseField name="fee" type="string">
  The fee amount associated with the deposit, typically '0' for incoming payments.
</ResponseField>

<ResponseField name="from_address" type="string">
  The sender's wallet address that the deposit came from.
</ResponseField>

<ResponseField name="hash" type="string">
  The blockchain transaction hash that uniquely identifies the deposit. Can be used to verify the transaction on a blockchain explorer.
</ResponseField>

<ResponseField name="reference" type="string">
  A unique reference generated for the deposit transaction. Useful for reconciling deposits and tracking them across logs or your system.
</ResponseField>

<ResponseField name="timestamp" type="string">
  The ISO 8601 timestamp of when the deposit was recorded, indicating when the transaction was detected on the blockchain.
</ResponseField>

<ResponseField name="transaction_id" type="string">
  The unique identifier of the transaction in Bitnob. Use it to look up or reconcile the deposit through the API.
</ResponseField>

```json
{
  "event_id": "0b7d6c1e-4f3a-4b8e-9a52-1c2d3e4f5a6b",
  "event": "deposit.success",
  "data": {
    "address": "Cev6GkmDnwSY3PvwhwBofwv65FrwcU1RxvF9Zt9aTJq4",
    "amount": "9000000",
    "chain": "tron",
    "currency": "USDT",
    "fee": "0",
    "from_address": "TQrY8tryqsYVCYS3MFbtffiPp2ccyn4rkr",
    "hash": "2426850248470ae3c24ff8ae62a5efbde325ea0c496475befb63947a65f5c122",
    "reference": "RCV_SBLNC_cc309ba8c361",
    "timestamp": "2025-12-12T20:38:23Z",
    "transaction_id": "8c3d1332-bd52-40f4-972f-768a2c4106f3"
  }
}
```

### Transfer stablecoin success

This webhook is fired when a stablecoin transfer is successfully completed on the blockchain.

<Note>
  The response shares the same payload structure as **Deposit Stablecoin Success**. Refer to the **Deposit Stablecoin Success** section for field explanations.
</Note>

```json
{
  "event": "transfer.success",
  "data": {
    "address": "TRMPscTMrXg21YuDFuvpXRUkwEbipHEZXN",
    "amount": "2000000",
    "chain": "tron",
    "currency": "USDT",
    "fee": "1000000",
    "hash": "4ae4308579587370accbd31dbfaebf3a97c8cfc7f68e2128ddec840349cafc60",
    "reference": "SND_SBLNC_80c7895d89e9",
    "timestamp": "2025-12-12T20:30:18Z"
  }
}
```

### Transfer stablecoin failed

This webhook is fired when a stablecoin transfer fails due to an error such as insufficient funds, invalid address, or network issues.

<Note>
  The response shares the same payload structure as **Deposit Stablecoin Success**. Refer to the **Deposit Stablecoin Success** section for field explanations.
</Note>

```json
{
  "event": "transfer.failed",
  "data": {
    "address": "TKVy2qjGyfxhPMvkeA8AEhv5XvpzLxGA5W",
    "amount": "2000000",
    "chain": "tron",
    "currency": "USDT",
    "fee": "0",
    "hash": "",
    "reference": "your-transfer-reference",
    "timestamp": "2025-12-12T20:30:00Z"
  }
}
```
