---
title: "Playground"
description: "Free developer utilities that run entirely in your browser: hashing, HMAC, JSON tools, encoders, and validators. Nothing you type leaves the page."
---

Every tool here runs locally in your browser. Nothing you type is uploaded, logged, or sent to a server, so they are safe to use with real payloads while you debug an integration.
