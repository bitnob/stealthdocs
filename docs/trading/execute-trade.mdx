Convert between stablecoins, Bitcoin, and NGN.

This endpoint allows you to perform a real-time asset conversion between supported assets. You can execute at current market rate or lock pricing using a previously generated quote ID.

## Endpoint

Full request and response schema: [Create Order](/api-reference/trading/submit-order) in the API reference.

```bash
POST /api/trading/orders
```

## Purpose

Use this endpoint to:

- Execute a trade between supported currencies (USDT, USDC, Bitcoin, NGN) for a user or system wallet
- Lock in pricing using a valid [quote](/api-reference/trading/create-quote) (`quote_id`)
- Route funds directly to your Bitnob wallet for the destination asset
- Track every trade via reference ID, [Get Order By ID](/api-reference/trading/get-order-by-id-or-reference), and webhooks

## Request

<ParamField body="base_currency" type="string" required>
  The base currency for the trade. One of `BTC`, `USDT`, `USDC`, or `NGN`.
</ParamField>

<ParamField body="quote_currency" type="string" required>
  The quote currency for the trade. One of `BTC`, `USDT`, `USDC`, or `NGN`. For naira trades, one side of the pair must be NGN.
</ParamField>

<ParamField body="side" type="string" required>
  `buy` or `sell`.
</ParamField>

<ParamField body="quantity" type="string" required>
  Amount of base currency to trade, in major units: `0.0001` (BTC) or `5000` (₦5,000).
</ParamField>

<ParamField body="price" type="string" required>
  The `price` from the quote you are executing against.
</ParamField>

<ParamField body="quote_id" type="string">
  The quote `id` from the create-quote response. Required for NGN pairs; optional for crypto pairs, where omitting it executes at the live market rate.
</ParamField>

<ParamField body="reference" type="string">
  Recommended. Your idempotency key for this trade. On NGN pairs, a repeat returns the original order. On crypto pairs, a repeat is **not** rejected, so look the order up before you retry. See [Idempotency](#idempotency).
</ParamField>

## Example request

```json
{
  "base_currency": "BTC",
  "quote_currency": "USDT",
  "side": "buy",
  "quantity": "0.0001",
  "price": "90822.540125",
  "quote_id": "a31798b2-3412-4e93-9211-e8a30164e934",
  "reference": "324567890"
}
```

### Example request (NGN pair)

For a naira trade, set base_currency to what you are spending and use side: "sell". quote_id is required: carry over the price and id from the quote.

```json
{
  "base_currency": "NGN",
  "quote_currency": "USDT",
  "side": "sell",
  "quantity": "5000",
  "price": "<price from the quote>",
  "quote_id": "<id from the quote>",
  "reference": "ngn_swap_001"
}
```

## Trade behaviour

If you send a `quote_id`:

- The rate is locked.
- If the quote has expired, the order is rejected with `422` and `Quote <id> has expired`. No funds move.
- If the quote doesn't exist, the order is rejected with `404`.

If you leave out `quote_id` (crypto pairs only):

- The order executes at the live market rate.
- The final amount can differ slightly from what you displayed.

NGN pairs always need a `quote_id`. Naira trades can't execute at a live market rate, and each NGN quote backs exactly one order.

## Idempotency

Send a unique `reference` with every trade, and generate it before the first attempt. What a repeated reference does depends on the pair:

- **NGN pairs:** the request returns the original order again, with the same `id`. Nothing executes a second time, even if you send a new `quote_id`.
- **Crypto pairs:** the reference isn't checked for uniqueness. A second request with the same reference can execute a second trade.

So after a timeout on a crypto order, don't resend blindly. Look it up first with `GET /api/trading/orders/{reference}`, and resend only if it isn't there. That lookup doesn't work for NGN orders (it returns `400` "invalid id"). For those, keep the order `id` from the response, or resend with the same reference to get the original order back.

## Webhooks

On completion, Bitnob will emit:

| Event | When It Fires |
|---|---|
| trade.completed | When trade is successfully executed |
| trade.failed | If the trade fails due to quote, balance, or system errors |

## Errors

| Code | Message | Description |
|---|---|---|
| 400 | Invalid asset pair | Use a supported pair (USDT, USDC, BTC, NGN). Naira trades need NGN on one side. |
| 400 | quote_id is required for NGN pairs | Request a quote first. |
| 400 | Validation failed | A required field is missing or malformed. `details` names each field. |
| 400 | Order too small: minimum 1.0 USDC | Crypto pairs have a minimum order size, and the message names it. |
| 403 | NGN not enabled | Naira trading isn't enabled on your account. Match on the status, not the text. |
| 404 | `Quote <id> not found` | The `quote_id` doesn't exist. |
| 422 | quote already consumed | NGN quotes back one order. Create a new quote. |
| 422 | `Quote <id> has expired` | The quote passed its `expires_at`. Create a new quote. Code is `PRECONDITION_FAILED`. |
| 422 | Insufficient balance | The source wallet doesn't have enough funds. No funds move. |
| 500 | Execution failed | Internal issue. Retry, or contact support. |
| 503 | We couldn't process your order right now. No funds were charged. | The trading service is unavailable. Look the order up before retrying. |
