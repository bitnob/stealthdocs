8 hands-on modules plus a capstone project on running Bitcoin Core from the command line.

Nothing here is simulated by an API. You run a real node in regtest, drive it with bitcoin-cli, and build up to scripted transaction flows. It covers:

- Installing and running bitcoind, and how Bitcoin Core is architected,
- Wallets, addresses, and UTXO control from the CLI,
- Using regtest to simulate blocks, confirmations, and chain state,
- Working with the RPC interface and developing against a local node.
